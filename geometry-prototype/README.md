# 几何作图原型（JSXGraph）

单文件原型：`index.html`，双击用浏览器打开即可运行。
JSXGraph 1.13.3 库已内联打包（`vendor/` 下保留原始文件备查），**完全离线可用**，
不依赖任何 CDN。

## 功能

1. **手动工具栏**（图标按钮，hover 显示说明）：选择 / 点 / **线段组**（线段、直线、射线共用一个图标位，
   点右下小箭头展开组内其他工具，`Esc` 或点组外收起）/ **平行线组**（过点平行直线、平行射线、
   等长/不等长平行线段共用一个图标位，同样点右下小箭头展开，`Esc` 可取消进行中的拾取）/ 圆 /
   **三点圆** / **圆弧**（圆心—起点—终点）/ **三点圆弧**（依次过 A、B、C，第 2 点决定走哪一侧）/
   **交点** / **中点**（只选已有点或线段，不新建点：进入前已选中线段则直接取中点，已选中一点则再点一个已有点即可；或点线段/多边形边直接取中点——悬停会高亮其两端点，或依次点两个已有点）/ **三角形中心组**
   （内心 / 外心 / 垂心共用一个图标位，点右下小箭头展开；依次点三个顶点，中心点实时联动；
   外心与内心缺省名 `O`，垂心缺省名 `H`，重名时自动顺延）/ **角平分线**
   （依次点三点，第 2 点为角顶点，生成 ∠ABC 的角平分线，顶点移动时方向联动）/ **垂线段**
   （先点起点，再点一条线段/多边形边作对边——悬停时高亮该边的两端点，点击直接取两端为对边、
   不新建点；或依次点对边两个点；生成起点到对边的垂线段，
   垂足为联动灰点（缺省名 `D`）；若垂足落在对边线段范围外，自动连接垂足与对边两端点，
   拖动使垂足进出范围时连接段自动显隐；退化情形如起点在对边直线上会提示重选，
   此时保留已选起点、停在选对边一步）/
   多边形 / 删除 / **轴对称** / **中心对称**，点选式作图。工具组会记住组内上次选择的工具。
   轴对称：先点一条直线/线段/射线作对称轴；中心对称：先点一个点作对称中心；
   之后点选（再点取消）或按住拖拽框选多个图形，**双击空白处**一次生成全部镜像，
   只记一条撤销。镜像点是联动的（原点/轴移动时自动跟随），共享定义点的对象只生成一份镜像点；
   二点圆弧镜像时自动交换起终点，保证弧段集合正确。`Esc` 取消拾取。
   作图时点击已有点附近会自动**吸附复用**（橙色高亮），不再重复建点；
   点击两线交叉处会自动生成**联动交点**（交点工具或作图吸附都可），图形移动时交点跟着动；
   点中直线/线段/圆与**多边形某条边**的交叉时同样生成联动交点，并把参与的那条边高亮成选中色（其余边不变）；
   选择工具：单击选中、`Shift`+点击多选（点多边形**内部**也可选中多边形，点优先于内部）；选中后在**选区内按住拖动可整体移动**所有已选对象
   （按中点走原生拖拽、其余点镜像跟随；按中线/圆/多边形或选区内空白走统一的手动平移——
   按中非点对象时本轮 JSXGraph 原生拖拽会被关闭，避免原生与手动双重搬运导致多选位移不一致）；
   纯单击已选对象收拢为单选，点击选区外空白取消选择；删除点会级联删除依赖它的图形
   （含三点圆弧的中间点）。
   点选时小目标优先：点和线重叠处点击会优先命中点。
   从动点（交点、中点、垂足、三角形中心、对称点、等长平行线段远端、垂线段垂足）统一显示为灰色，
   但还有灵活度、未被完全确定的点不置灰（曲线约束点可沿曲线滑动、不等长平行线段远端可沿方向拉动）；
   自由点保持默认色，选中/闪烁高亮时仍按原色恢复。
2. **对象列表**（画板左侧）：显示每个对象的中文定义（点及坐标、交点及父对象、
   三点圆的三个父点、三点圆弧的依次三点等）；行首圆点点击切换显示/隐藏；
   点击行内其他区域会切到选择工具并选中该对象；双击某行可修改对象名称（引用自动重写，支持撤销）。
   画板操作（新建/删除/清空/撤销/重做/拖拽结束）后列表自动同步；拖拽过程中节流刷新。
3. **视图操作**：滚轮**直接**以鼠标位置为中心缩放（无需按 Ctrl）；选择模式下，
   在选区内按住拖动移动已选对象，拖动选区外空白背景平移视图；
   画板右下角可拖动调整窗口大小（内容自动重绘）。
4. **撤销/重做**：工具栏按钮 + `Ctrl/Cmd+Z`、`Ctrl/Cmd+Y`（`Ctrl/Cmd+Shift+Z`），
   多步作图、删除、JSON 渲染、整体移动均可撤销（输入框内保留原生文本撤销）。
   单个点的原生拖拽（按下命中点、松开时真移动了）也会把"按下时"快照入栈，可一键撤销；
   纯点击不产生空历史。行首圆点的显示/隐藏同样记入撤销（快照记录 `visible:false`，重建时恢复）。
   撤销/重做/清空时批量重建只触发一次重绘、一次列表刷新；撤销/重做/JSON 渲染
   另用"冻结帧"盖住旧画面（克隆整个画板容器：svg 图形层 + HTML 标签层都要带上，
   因为点/线的标签是容器里的 div 而不是 svg 内容；罩子复制画板容器的计算样式，
   圆角/边框/背景像素级一致），等 JSXGraph 异步量取标签真实尺寸并校准位置完成后再揭开，避免闪烁。
   点拖拽带磁吸，优先级：先贴附近的线对象、再贴网格点。拖到离线段/直线/射线/圆/圆弧
   12 屏幕像素内先吸到线上（线段取段内最近点、射线只取正向、圆弧超范围取最近端点；
   以该点为定义点的曲线、辅助垂线段、不可见曲线不参与，避免自吸附退化）；
   附近无曲线时，离整数网格点 6 屏幕像素内吸到网格点。每次移动都重新判定，
   拖离即松开、不锁死；glider 约束在曲线上不吸。多选/单对象整体移动不做磁吸、严格跟随鼠标刚性平移。
   **拖点到线松手加约束**：选择模式下拖动自由点贴近某条线对象时，该线以橙色高亮
   （已选中的红线保持红色不覆盖）；松手即把该点转为约束在该线上的动点（glider），
   对象列表中显示"在……上"，状态栏提示已约束。以下情况拒绝约束并提示原因：
   点已是 glider、固定点、派生点（交点/中点/垂足/三角形中心/对称点/平行端点等）、
   该曲线直接或间接依赖该点（防循环依赖）。约束转换与本次拖动合并为一步撤销/重做。
   选区内（对象包围盒外扩约 16 屏幕像素）按下拖动只移动
   已选对象、绝不平移视图；选区外空白按下拖动才平移视图。
5. **AI 文字指令**：输入中文指令 → 右侧显示"AI 生成的语句" → 自动生成 JSON → 一键渲染到画板。
6. **JSON 构造步骤**：可手改 JSON 后点"渲染到画板"，带校验和错误提示。

> 当前 AI 为演示版 `mockAI()`（正则匹配几种句式）。正式版把该函数换成对国产大模型
> API 的 `fetch` 调用即可，prompt 约束见下。

## JSON 构造步骤 schema

顶层为数组，每一步：

```json
{ "type": "point", "id": "A", "coords": [1, 2] }
```

| type | 必填字段 | 说明 |
|---|---|---|
| `point` | `coords: [x, y]`，可选 `on: 曲线id` | 创建点；`on` 表示约束在曲线上的动点（glider） |
| `segment` / `line` / `ray` | `p1`, `p2` | 线段 / 直线 / 射线，端点为 id 或 `[x,y]` |
| `circle` | `center` + `radius` 或 `center` + `through` 或 `through3: [p1,p2,p3]` | 圆 / 三点圆（三点不共线） |
| `arc` | `center`, `p1`, `p2` | 圆弧：圆心—弧起点—弧终点，逆时针绘制 |
| `arc3` | `through3: [A, B, C]` | 三点圆弧：三点外接圆上依次经过 A→B→C 的圆弧（三点不共线、不重复） |
| `ellipse` / `hyperbola` | `f1`, `f2`, `p` | 椭圆 / 双曲线：两焦点 `f1`/`f2` + 曲线上一点 `p`（三点不共线、不重复，焦点/曲线上点为 id 或 `[x,y]`） |
| `parabola` | `focus`, `directrix` | 抛物线：焦点 `focus` + 准线 `directrix`（直线/线段 id，焦点不能在准线上） |
| `polygon` | `points: [...]`（≥3） | 多边形，顶点为 id 或坐标 |
| `midpoint` | `p1`, `p2` | 中点；点击线段/多边形边可直接取其中点（悬停高亮两端点；重复点击同一线段/点对会复用已存在的中点，不重复创建） |
| `tricenter` | `kind: incenter\|circumcenter\|orthocenter`, `points: [A,B,C]` | 三角形内心 / 外心 / 垂心（顶点移动时联动；内心=边长加权平均，外心=外接圆圆心，垂心=欧拉关系 H=A+B+C−2O） |
| `perpendicular` | `line`, `point` | 过点作垂线；`id` 注册垂足，`id_line` 注册垂线本身 |
| `intersection` | `e1`, `e2`, `index?` | 两对象交点（index 选第几个交点，默认 0） |
| `intersection`（多边形边） | `e1`, `polygon`, `edge`, `index?` | 直线/线段/圆与多边形某条边的交点：`polygon` 为多边形 id，`edge` 为边序号（0 起）；描点时点中这种交叉会自动生成联动交点，并把参与的那条边高亮成选中色，其余边不变 |
| `pline` / `pray` | `point`, `ref` | 过点作平行直线 / 平行射线：`point` 为过点 id，`ref` 为参照线段/直线/射线 id；射线沿参照点1→点2方向 |
| `pseg` | `point`, `ref`, `end?` | 过点作等长平行线段：起点为 `point`，与参照等长且平行；远端端点为可见的固定派生点（不可拖动），`end` 为其 id（不填自动生成） |
| `psegfree` | `point`, `ref`, `len`, `end?` | 过点作不等长平行线段：`len` 为有向长度（可为负，表示反方向）；远端端点为约束在平行方向上的动点，可沿方向拖动调长度，`end` 为其 id（不填自动生成） |
| `mirrorpt` | `of`, `axis`, `t: axial\|central` | 对称镜像点：`of` 为原点 id，`axis` 为对称轴（线）或对称中心（点）id，联动跟随 |
| `bisector` | `vertex`（角顶点）, `p1`, `p2` | ∠p1-vertex-p2 的角平分线（无限直线，方向实时联动） |
| `perpseg` | `point`（起点）, `p1`, `p2`（对边两端点） | 垂线段：起点到对边的垂线段；`id` 注册垂线段本身，垂足（函数坐标联动点，缺省名 `D`）与越界连接段随步骤重建；垂足落在对边范围外时 H–A、H–B 两条连接段同时显示，范围内则同时隐藏 |
| 任意曲线/多边形步骤 | 可选 `mirror: {of, axis, t}` | 对称生成的曲线/多边形附加的镜像引用（`of` 为原对象 id），用于列表标注、删除级联与改名 |

- `id` 可选（不填自动生成），但被其他步骤引用时必须填写。
- 引用方式：`"p1": "A"`（已定义的 id）或 `"p1": [3, 4]`（内联坐标，会自动建点）。

示例：

```json
[
  { "type": "point", "id": "O", "coords": [0, 0] },
  { "type": "circle", "id": "c1", "center": "O", "radius": 3 },
  { "type": "point", "id": "A", "coords": [-4, 0] },
  { "type": "point", "id": "B", "coords": [4, 0] },
  { "type": "point", "id": "C", "coords": [0, 3] },
  { "type": "circle", "id": "c2", "through3": ["A", "B", "C"] },
  { "type": "segment", "id": "s1", "p1": "A", "p2": "B" },
  { "type": "point", "id": "P", "coords": [5, 1] },
  { "type": "perpendicular", "id": "H", "line": "s1", "point": "P" }
]
```

## 接入真实大模型（替换 mockAI）

system prompt 要点（要求模型**只输出 JSON**，不掺杂解释文字）：

> 你是一个几何作图助手。用户用中文描述要画的图形，你只能输出一个 JSON 数组，
> 每一步遵循以下 schema：{"type": "point"|"segment"|"line"|"circle"|"polygon"|
> "midpoint"|"tricenter"|"bisector"|"perpendicular"|"intersection", "id": "唯一标识", ...}。
> 坐标用 coords:[x,y]；引用用 id 字符串。不要输出除 JSON 之外的任何内容。

前端拿到模型返回后：`JSON.parse` → `renderSteps()` 渲染；模型另用一句话中文描述
做了什么，显示在"AI 生成的语句"区（语句与 JSON 分开传，避免解析污染）。
