JSON schema 说明

顶层为步骤数组，每步形如 {"type":"point","id":"A","coords":[x,y]}。 支持的类型：point（coords）、segment / line（p1,p2）、 circle（center+radius 或 center+through）、polygon（points 数组）、 midpoint（p1,p2）、perpendicular（line,point，注册垂足）、 intersection（e1,e2,index）。点/线/圆的引用可用 id 字符串或 [x,y] 坐标。 完整说明见 README.md。
